# Thiệp chúc mừng 20/11

Thiệp điện tử chúc mừng Ngày Nhà giáo Việt Nam, tối ưu cho điện thoại.
Chạm con dấu để xem phong bì bung mở và tấm thiệp trượt ra, phóng lớn.

## Xem trên máy

Mở `thiep.html` trong trình duyệt. Giữ ảnh `Thiệp chúc mừng.png` cùng thư mục với file HTML.

## Triển khai lên Vercel

1. Trong Vercel, chọn **Add New → Project** và import repo `tranminhthinh1204/ThiepChucMung2011`.
2. Chọn **Framework Preset: Other**, giữ **Root Directory** ở thư mục gốc và không đặt Build Command.
3. Nhấn **Deploy**, sau đó gửi đường link được cấp cho người nhận.

`vercel.json` đã cấu hình đường dẫn `/` hiển thị `thiep.html`.
Trang dùng HTML, CSS và JavaScript thuần, không cần cài thư viện hay biến môi trường.

Tham khảo: [Cấu hình dự án Vercel](https://vercel.com/docs/project-configuration).
